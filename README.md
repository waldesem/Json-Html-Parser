# Json-Html-Parser

Json-Html-Parser is a Vue-based web application and Chromium extension that converts JSON data to HTML.

## Use extension

1. Download the latest release from the [releases page](https://github.com/waldesem/Json-Html-Parser/releases)
2. Unzip the downloaded file
3. Open `chrome://extensions`, enable **Developer mode** and click **Load unpacked**, selecting the `dist` folder
4. Clicking the extension icon opens a popup with the **Открыть приложение** button. The button opens the main page (`index.html`) in a new tab.
